# Security policy

## Supported versions

No version is tagged yet. Only the `main` branch is supported.

| Version          | Supported |
| ---------------- | --------- |
| `main` (unreleased) | ✅     |

## Reporting a vulnerability

Do not open a public issue or pull request for a vulnerability. Report it privately through GitHub's private vulnerability reporting: the repository's **Security** tab, then **Report a vulnerability**. Include the affected file, the steps to reproduce and the impact you expect.

## Response time

No response time is promised. The owner acts on reports as soon as practical.
