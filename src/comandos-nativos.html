      Fora do Desktop

      Existem, mas não aparecem no app

      Estão no binário só na versão de terminal. No Desktop o app oferece botões próprios no lugar deles:

      • /btw faz uma pergunta paralela sem interromper a conversa.
      • /rewind (também /undo) volta código e conversa a um ponto anterior.

      Para usá-los, abra claude no painel Terminal do app. A documentação lista o que não está no Desktop ↗.

      Na documentação oficial

      Como a Anthropic classifica

      A referência de comandos reúne tudo numa tabela só e marca cada linha de um de três jeitos:

      • Comando embutido: o comportamento está programado no próprio Claude Code. É a maioria.
      • Skill: uma skill que vem com o Claude Code. Funciona como as skills que você escreve: um roteiro entregue ao Claude.
      • Workflow: um fluxo embutido que reparte o trabalho entre muitos subagentes.

      Nem todo comando aparece para todo mundo: depende da plataforma, do plano e do ambiente. Os comandos que abrem diálogos de terminal não existem no Desktop, que oferece telas próprias no lugar.
