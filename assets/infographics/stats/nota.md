# /stats: descrição completa

Categoria: Diagnóstico e uso. Tipo: comando embutido do Claude Code.

## O que faz
Abre o painel de uso já posicionado na aba Stats. Na documentação, é atalho de /usage.

## Por que usar
Serve para ir direto às estatísticas de uso quando é só isso que você quer ver.

## Como usar
Rode /stats. O mesmo painel também é aberto por /usage.

## Quando usar
Quando você quer ver as estatísticas de uso direto na aba Stats.

## Observação
No app aparece como comando próprio: o menu mostra só stats, sem usage (stats). Testado no app: funcionou. Doc oficial: alias de /usage, abre na aba Stats.

## O que acontece no fluxo do prompt e do motor
1. Você digita /stats.
2. Abre o painel de uso.
3. Seleciona a aba Stats.
4. Mostra as estatísticas.

## Exemplos
- /stats: Abre o painel de uso na aba Stats.
- /stats: Mostra a mesma tela que o /usage abre.
- /stats: Útil quando você só quer as estatísticas de uso.

## Comandos relacionados
- /usage: Painel de custo e uso do plano.

## Armadilhas
- No app, o menu mostra só stats, sem usage (stats).
