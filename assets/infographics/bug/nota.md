# /bug: descrição completa

Categoria: Diagnóstico e uso. Tipo: alias do /feedback.

## O que faz
No app, /bug é enviado para /feedback, que abre o mesmo diálogo de envio, com consentimento antes do envio.

## Por que usar
Quem conhece o nome antigo encontra o comando atual sem procurar.

## Como usar
Use /feedback, que é o nome atual. Veja o cartão de /feedback na página.

## Quando usar
Quando você lembra do nome antigo e quer relatar um problema ao fabricante.

## Observação
No app aparece como /feedback (bug). Testado no app: vai para /feedback. A referência indica /share como alias e a v2.1.229 como versão mínima para o diálogo no VS Code.

## O que acontece no fluxo do prompt e do motor
1. Você digita /bug.
2. O app envia para /feedback.
3. Abre o diálogo de envio.
4. Você confirma antes do envio.

## Exemplos
- /bug: Abre o diálogo de envio, como o /feedback.
- /feedback: Nome atual do mesmo comando.
- /bug a busca de arquivos demora muito: Relato direto, com o texto do problema.

## Comandos relacionados
- /feedback: Envia relato ao fabricante.

- No app, aparece como /feedback (bug).
