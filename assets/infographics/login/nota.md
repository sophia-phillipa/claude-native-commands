# /login: descrição completa

Categoria: Ajustes e permissões. Tipo: comando embutido do Claude Code.

## O que faz
Entra na sua conta Anthropic. Em algumas situações, o mesmo comando aparece como troca de conta.

## Por que usar
É o passo para conectar o Claude Code à sua conta antes de começar a trabalhar.

## Como usar
Rode /login e siga as instruções na tela para entrar ou trocar de conta.

## Quando usar
Ao começar a usar o Claude Code numa máquina nova, ou quando a sessão precisa usar outra conta.

## Observação
Documentado na referência oficial. Descrição oficial na tabela de comandos.

## O que acontece no fluxo do prompt e do motor
1. Você digita /login
2. Abre o fluxo de entrada
3. Você entra na conta Anthropic
4. Sessão fica ligada à conta

## Exemplos
- /login: Abre o fluxo de entrada na conta Anthropic.
- /login: Útil quando a sessão está com uma conta que não é a que você quer usar.
- /login: Rode de novo se a sessão tiver perdido o acesso à conta.

## Comandos relacionados
- /logout: Para entrar de novo depois de sair.

## Armadilhas
- Depois de sair, precisa de /login.
