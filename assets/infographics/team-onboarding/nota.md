# /team-onboarding: descrição completa

Categoria: Diagnóstico e uso. Tipo: comando embutido do Claude Code.

## O que faz
Gera um guia para colegas começarem no Claude Code, montado a partir do seu uso recente. O comando examina o histórico dentro de uma janela de dias e escreve o roteiro. A lista de ferramentas liberadas inclui editar um arquivo ONBOARDING.md.

## Por que usar
Um guia baseado no que você realmente faz é mais útil que um genérico: mostra os comandos e hábitos que funcionam no seu time.

## Como usar
Rode /team-onboarding dentro do projeto.

## Quando usar
Quando entra gente nova no time, ou quando você quer registrar os hábitos de uso que funcionam antes que se percam.

## Observação
A tabela de comandos da referência oficial lista o comando; a descrição dela confere com o cartão.

## O que acontece no fluxo do prompt e do motor
1. Você digita /team-onboarding.
2. O motor lê seu histórico recente.
3. O motor escreve o roteiro do guia.
4. O guia fica pronto para os colegas.

## Exemplos
- /team-onboarding: gera o guia a partir do seu uso.
- /team-onboarding: rode na raiz do repositório, para o guia ficar junto do código.
- /team-onboarding: revise o texto e remova o que for específico demais antes de compartilhar.

## Comandos relacionados
- /doctor: check-up da instalação (mesma categoria, Diagnóstico e uso).

## Armadilhas
- Compartilhar sem revisar o texto.
- Só enxerga o uso recente.
